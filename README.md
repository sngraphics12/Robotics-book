# Physical AI & Humanoid Robotics – Interactive Online Book with RAG Tutor

**Author:** Sadia Naz

This repository contains the source code for an **AI-powered online textbook** on Physical AI and Humanoid Robotics, complete with a **Retrieval-Augmented Generation (RAG) tutor** for interactive learning.

---

## Project Structure

The repository has two main components:

### 1. Online Book (`/book-app`)
- Built with **Docusaurus**.
- Provides a professional, navigable textbook interface with **parts, chapters, and sections**.
- Fully responsive and optimized for online reading.

### 2. RAG Tutor (`/rag-backend`)
- Built with **FastAPI**.
- Enables readers to **ask questions** about the book content and get **context-aware answers with citations**.
- Connects seamlessly with the book frontend.
